**English** · Download **`com.kuletx.forttreasure-*.apk`** below and open it on your phone (allow installing from your browser or file manager if Android asks). Fortnite on Android records no replays, so you count chests with the floating counter while you play.

**What's new in 1.6.0** (first release of the Android app)
- **The floating counter stays on**: it now runs as a foreground service with a notification showing the match, session, chests and treasures, with **+1 chest** and **Stop** buttons. Android no longer closes it in the middle of a match
- **Match and session numbers stay numbers**: "Match 2 · Session 1" no longer turns into the chest count
- **Treasure Picker**: log the weekly prize, Pirate Shop access or a gizmo, live or afterwards in the match log
- **Island loot odds**: your chance over N chests, with Treasure Hour and custom rates
- **Tests and CI**: 20 automated tests run on every push, and each release builds the APK

An update keeps your data only if every APK is signed with the same key: see the signing section of AGENTS.md.
